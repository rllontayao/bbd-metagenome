## Taxonomic Classification Using GTDB-Tk

Following genome quality assessment with CheckM, the 17 selected genome
bins with estimated completeness greater than 15% were classified using
the Genome Taxonomy Database Toolkit (GTDB-Tk).

The purpose of this step was to identify the bacterial groups
represented in the Black Band Disease (BBD) metagenome and investigate
which microorganisms may contribute to the metabolic processes
associated with the disease.

GTDB-Tk uses conserved marker genes and reference genomes to assign
taxonomic classifications to metagenome-assembled genomes (MAGs).

### Taxonomic Classification Results

GTDB-Tk produced a bacterial classification summary in
`gtdbtk.bac120.summary.tsv`.

Selected classifications relevant to our subsequent metabolic pathway
analysis are presented below.

| Genome bin | Phylum           | Order             | Family          | Genus         |
|------------|------------------|-------------------|-----------------|---------------|
| metabat.40 | Cyanobacteria    | Cyanobacteriales  | Desertifilaceae | Roseofilum    |
| metabat.21 | Firmicutes_A     | Lachnospirales    | Vallitaleaceae  | Unclassified  |
| metabat.69 | Campylobacterota | Campylobacterales | Arcobacteraceae | Halarcobacter |

The classification of `metabat.40` as *Roseofilum* is particularly
relevant because this genus includes filamentous cyanobacteria
associated with coral Black Band Disease.

The presence of this cyanobacterial genome is consistent with the
expected microbial composition of BBD lesions, where photosynthetic
microorganisms form an important component of the microbial community.

The bin `metabat.21` was classified within the family Vallitaleaceae,
while `metabat.69` was classified as *Halarcobacter* within the family
Arcobacteraceae.

These classifications provide a taxonomic basis for interpreting the
metabolic pathways identified during subsequent functional analysis.

### Interpretation

The GTDB-Tk results demonstrate that the selected genome bins represent
different bacterial lineages within the BBD microbial community.

In particular, the identification of *Roseofilum* provides a useful link
between the taxonomic composition of the metagenome and the potential
for photosynthesis.

However, taxonomic classification alone cannot confirm which metabolic
processes are occurring. Functional gene annotation and pathway
inference are needed to investigate the metabolic capabilities of these
microorganisms.

Furthermore, many of the selected genome bins have relatively low
estimated completeness, which may limit the resolution of their
taxonomic classifications.

### Processing Log

The 17 selected genome bins were copied from the MetaBAT2 output
directory into the GTDB-Tk input directory.

``` bash
cd ~/bbd-metagenome/gtdbtk

while read bin;do
  cp "../metabat/bins_bbd/${bin}.fa" genomes
done < ../checkm/bbd_topbins.txt
```

This loop used the bin identifiers stored in `bbd_topbins.txt` to copy
the corresponding FASTA files into `gtdbtk/genomes/`.

The copied files were checked using:

``` bash
ls genomes
```

GTDB-Tk was then run through the SLURM scheduler using the script
[run_gtdbtk.sh](gtdbtk/run_gtdbtk.sh).

The main classification command was:

``` bash
gtdbtk classify_wf -x fa --cpus 2 --genome_dir genomes --out_dir out --skip_ani_screen
```

The `classify_wf` option performed the taxonomic classification
workflow, `-x fa` specified the FASTA extension, `--cpus 2` allocated
two processing threads, and `--genome_dir` and `--out_dir` specified the
input and output directories.

The job was submitted using:

``` bash
sbatch run_gtdbtk.sh
```

After completion, the classification summary was checked and copied into
the main GTDB-Tk directory so it could be included in the GitHub
repository.

``` bash
ls -l out/gtdbtk.bac120.summary.tsv

cp out/gtdbtk.bac120.summary.tsv .
```

The taxonomic classifications were subsequently cross-referenced with
the metabolic pathway results generated by MinPath.
